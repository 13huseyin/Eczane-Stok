# Eczane Stok Takip Sistemi

## Ne İşe Yarar?
C# ve Windows Forms ile geliştirilmiş, eczanelerin ilaç stoklarını (ID, ad, şirket, tür, miktar) yönetmesini sağlayan bir masaüstü uygulamasıdır.

## Temel Özellikler
* **Listeleme:** Tüm stok verilerini tabloda gösterir.
* **CRUD İşlemleri:** Yeni ilaç ekler, mevcut kayıtları günceller ve siler.
* **Hızlı Düzenleme:** Listeden seçilen kaydı otomatik olarak kutucuklara aktarır.
* **Güvenlik:** SQL Injection açıklarına karşı `SqlParameter` kullanılarak güvenli altyapıyla tasarlanmıştır.
